# 我的電腦

讀取你的電腦硬體資訊，算出所需的最小電量與最大電量。純靜態網頁，可直接部署到 GitHub Pages。

## 使用方式

1. 開啟網頁，按「開始掃描」。
2. 網頁會盡量讀取硬體資訊：作業系統、處理器執行緒數、顯示晶片、記憶體、螢幕、電池、儲存空間、觸控。
3. 在「零件配置」確認偵測結果；讀不到的零件（標示「待選擇」）點卡片自行選擇，也可以按「一鍵填入常見值」。
4. 按「計算電量」，查看最小電量、最大電量、建議的電源供應器（或變壓器、充電器）瓦數與每日用電度數。

## 卡片狀態

| 標示 | 意思 |
| --- | --- |
| 已偵測 | 由瀏覽器直接讀到 |
| 推測 | 依讀到的資訊推測，請確認 |
| 待選擇 | 瀏覽器讀不到，需要自行選擇 |
| 已選擇 | 使用者自己選的 |
| 常見值 | 由「一鍵填入常見值」帶入 |

## 計算方式

- 最小電量：每個零件的待機耗電加總，除以電源在低負載時的轉換效率，再加上外接螢幕。
- 最大電量：每個零件的滿載耗電加總，除以電源的轉換效率，再加上外接螢幕。
- 建議電源供應器：主機滿載耗電再加 30% 餘裕，取最接近的常見規格。
- 數值為估算，僅供參考。

## 瀏覽器限制

- 處理器型號、主機板、硬碟、電源供應器無法從網頁讀取。
- 記憶體容量在 Chrome / Edge 最多只回報 8 GB；Firefox、Safari 不提供。
- 顯示卡名稱在部分瀏覽器（Firefox 隱私模式、Safari）會被隱藏或簡化。
- 電池資訊只有 Chrome / Edge 提供。

所有偵測都在瀏覽器裡完成，不會上傳任何資料；選擇結果只存在瀏覽器的 localStorage。

## 部署到 GitHub Pages

把整個資料夾推上 GitHub，在 Settings → Pages 選擇分支與根目錄即可。

## 檔案結構

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 頁面與四個場景（封面、掃描、零件配置、電力報告） |
| `css/style.css` | 樣式；橫式 1920×1080、直式 1080×1920 設計稿，依視窗等比縮放 |
| `js/data.js` | 零件選項與耗電資料庫（含顯示卡型號對照） |
| `js/detect.js` | 讀取硬體資訊 |
| `js/app.js` | 場景切換、零件選擇、電量計算 |
| `favicon.svg` | 網站圖示 |
