# 我的電腦

一步步填寫電腦硬體，算出所需的最小電量與最大電量。純靜態網頁，可直接部署到 GitHub Pages。

## 使用方式

1. 開啟網頁，按「開始填寫」。
2. 先選裝置類型（桌上型電腦、筆記型電腦、迷你主機、手機／平板），再依類型一題一題回答。
3. 每一題都會說明去哪裡查資料（例如工作管理員的哪一頁）；選項多的題目會分層引導，例如顯示卡：品牌 → 系列 → 型號，也可以直接輸入關鍵字搜尋。
4. 每一題都可以按「略過這題」，略過的零件不計入；知道確切耗電也可以「自己輸入瓦數」。
5. 最後查看電力報告：最小電量、最大電量、建議的電源供應器（或變壓器、充電器）瓦數與每日用電度數。點明細裡的項目或「補填」可以回去修改。

## 計算方式

- 最小電量：每個零件的待機耗電加總，除以電源在低負載時的轉換效率。
- 最大電量：每個零件的滿載耗電加總，除以電源的轉換效率。
- 建議電源供應器：主機滿載耗電再加 30% 餘裕，取最接近的常見規格。
- 略過的零件不計入；沒填的電源供應器以 80 PLUS 銅牌（約 85%）的效率估算。
- 數值為估算，僅供參考。

答案只存在瀏覽器的 localStorage，不會上傳任何資料。

## 部署到 GitHub Pages

把整個資料夾推上 GitHub，在 Settings → Pages 選擇分支與根目錄即可。

## 檔案結構

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 頁面與三個場景（封面、引導填寫、電力報告） |
| `css/style.css` | 樣式；橫式 1920×1080、直式 1080×1920 設計稿，依視窗等比縮放 |
| `js/data.js` | 零件選項與耗電資料庫（含顯示卡型號對照） |
| `js/app.js` | 場景切換、引導填寫、電量計算 |
| `favicon.svg` | 網站圖示 |
